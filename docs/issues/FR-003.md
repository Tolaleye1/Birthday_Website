# [FR-003] Unified Tribute Submission Page

## Labels
`MUS`, `enhancement`, `submissions`

## User Story
As a guest, I want one simple page for all contribution types, so that I can choose the format that suits me best.

## Proposed Solution

### Overview
Create a single submission page at `/submit-tribute` with 3 tabs (Text, Photo, Video) so guests do not need to guess where each contribution belongs.

### Implementation Flow
1. Present contribution types as tab pills in a switcher bar.
2. Show only the fields required for the selected type.
3. Reuse shared validation and storage patterns (signed upload URL → PUT → confirm).

### Technical Approach

```ts
type TributeTab = 'text' | 'photo' | 'video'
```

### Key Considerations
- Type switching should not feel confusing on mobile.
- Text tributes should remain the fastest flow.
- Photo and video variants share the same upload infrastructure.

## Acceptance Criteria

- [x] Guests can submit a text tribute with name and message. ✅
- [x] Guests can submit a photo with name and caption. ✅
- [x] Guests can submit a video from this page under the same validation rules as the dedicated video page. ✅
