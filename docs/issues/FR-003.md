# [FR-003] Unified Wish Submission Page

## Labels
`MUS`, `enhancement`, `submissions`

## User Story
As a guest, I want one simple page for all contribution types, so that I can choose the format that suits me best.

## Proposed Solution

### Overview
Create a single submission page with clearly separated text wish, photo wish, and video wish flows so guests do not need to guess where each contribution belongs.

### Implementation Flow
1. Present contribution types as tabs, segmented controls, or stacked cards on mobile.
2. Show only the fields required for the selected type.
3. Reuse shared validation and storage patterns wherever possible.

### Technical Approach

```ts
type WishVariant = 'text' | 'photo' | 'video'
```

### Key Considerations
- Type switching should not feel confusing on mobile.
- Text wishes should remain the fastest flow.
- Photo and video variants should share upload infrastructure where practical.

## Acceptance Criteria

- [ ] Guests can submit a text wish with name and message.
- [ ] Guests can submit a photo with name and caption.
- [ ] Guests can submit a video from this page under the same validation rules as the dedicated video page.
