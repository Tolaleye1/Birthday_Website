# [FR-001] Landing Page and Primary CTAs

## Labels
`MUS`, `enhancement`, `public-site`

## User Story
As a guest, I want an inviting landing page with obvious next steps, so that I can quickly participate in the celebration.

## Proposed Solution

### Overview
Create a high-impact mobile-first landing page that introduces the celebrant, sets the emotional tone, and routes guests toward either submitting a wish or uploading a video.

### Implementation Flow
1. Establish a hero with celebrant introduction, visual branding, and event tone.
2. Surface two primary CTAs: submit a wish and upload a video.
3. Add a supporting preview of gallery and wishes content to encourage participation.

### Technical Approach

```ts
type LandingCTA = {
  label: string
  href: '/' | '/submit-wish' | '/upload-video' | '/gallery' | '/wishes'
  emphasis: 'primary' | 'secondary'
}
```

### Key Considerations
- The page should load quickly on mobile.
- CTA hierarchy must be clear above the fold.
- The visual tone should feel celebratory rather than corporate.

## Acceptance Criteria

- [x] The landing page includes a celebrant introduction and strong brand styling. ✅
- [x] Users can clearly navigate to `Submit a Wish` and `Upload Video`. ✅
- [x] The page works cleanly on small mobile screens without horizontal overflow. ✅
