# [FR-004] Media Gallery with Photo, Video, and Laitan's Gallery Views

## Labels
`MUS`, `enhancement`, `gallery`

## User Story
As a visitor, I want to browse photos and videos separately, so that I can enjoy the celebration content in an organized way.

## Proposed Solution

### Overview
Build a gallery page at `/gallery` with **3 tabbed views**: guest Videos, guest Photos, and Laitan's Gallery (admin-curated photos + videos).

### Implementation Flow
1. Fetch non-deleted media contributions grouped by type.
2. Fetch admin-curated items from `laitan_gallery` table.
3. Render photos in a responsive grid, videos in video cards, Laitan's Gallery items with play overlays for video type.
4. Add empty states. CTA hidden on Laitan's Gallery tab.

### Technical Approach

```ts
type GalleryTab = 'videos' | 'photos' | 'laitan'
```

### Key Considerations
- Video cards should favor previews and avoid heavy autoplay behavior.
- Laitan's Gallery renders both photos and videos (media_type field).
- Tab switcher must not overflow on mobile (overflow-x-auto fix applied).
- The page must degrade gracefully when content is still sparse.

## Acceptance Criteria

- [x] Gallery users can switch between Videos, Photos, and Laitan's Gallery tabs. ✅
- [x] Photo and video submissions display only if not deleted. ✅
- [x] Empty states are provided when any tab has no contributions. ✅
- [x] CTA is hidden on Laitan's Gallery tab. ✅
- [x] Tabs do not overflow on mobile screens. ✅
