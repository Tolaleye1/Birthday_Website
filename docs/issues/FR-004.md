# [FR-004] Media Gallery with Photo and Video Views

## Labels
`MUS`, `enhancement`, `gallery`

## User Story
As a visitor, I want to browse photos and videos separately, so that I can enjoy the celebration content in an organized way.

## Proposed Solution

### Overview
Build a gallery page with separate views for photo and video contributions, optimized for mobile browsing and progressively scalable content volume.

### Implementation Flow
1. Fetch non-deleted media contributions grouped by type.
2. Render photos in a responsive grid and videos in a video-focused card layout.
3. Add empty states and pagination hooks for future scale.

### Technical Approach

```ts
type GalleryFilter = 'photos' | 'videos'
```

### Key Considerations
- Video cards should favor previews and avoid heavy autoplay behavior.
- Photo browsing should feel warm and scrapbook-like rather than plain.
- The page must degrade gracefully when content is still sparse.

## Acceptance Criteria

- [ ] Gallery users can switch between photo and video views.
- [ ] Photo and video submissions display only if not deleted.
- [ ] Empty states are provided when one or both media types have no contributions.
