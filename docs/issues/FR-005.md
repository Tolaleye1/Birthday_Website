# [FR-005] Tributes Wall

## Labels
`MUS`, `enhancement`, `tributes`

## User Story
As a visitor, I want to read everyone's written tributes in a beautiful wall, so that the collective love feels memorable and immersive.

## Proposed Solution

### Overview
Design a dedicated tributes wall at `/tributes` that turns text submissions into visually rich cards in a CSS-columns masonry layout.

### Implementation Flow
1. Fetch text contributions ordered by recency.
2. Render them in a masonry card system with avatar initials, time-ago formatting, and quoted styling.
3. Handle empty states and variable content lengths gracefully.

### Technical Approach

```ts
type TextTribute = {
  id: string
  submitter_name: string
  message: string
  created_at: string
}
```

### Key Considerations
- Readability takes priority over decorative treatment.
- Long messages should wrap cleanly on mobile.
- Cards should feel part of the same design system as the hero and gallery.
- Avatar initials rotate through brand colors.

## Acceptance Criteria

- [x] All text tributes appear on the tributes wall in a masonry layout. ✅
- [x] Each item clearly shows the submitter's name and message. ✅
- [x] The page remains readable for short and long tributes on mobile devices. ✅
