# [FR-005] Wishes Wall

## Labels
`MUS`, `enhancement`, `wishes`

## User Story
As a visitor, I want to read everyone’s written wishes in a beautiful wall, so that the collective love feels memorable and immersive.

## Proposed Solution

### Overview
Design a dedicated wishes wall that turns text submissions into visually rich cards, tiles, or ribbons rather than plain paragraphs.

### Implementation Flow
1. Fetch text contributions ordered by recency.
2. Render them in an appealing card system with strong typography.
3. Handle long wishes, empty states, and variable content lengths gracefully.

### Technical Approach

```ts
type TextWish = {
  id: string
  submitterName: string
  message: string
  createdAt: string
}
```

### Key Considerations
- Readability takes priority over decorative treatment.
- Long messages should wrap cleanly on mobile.
- Cards should feel part of the same design system as the hero and gallery.

## Acceptance Criteria

- [ ] All text wishes appear on the wishes wall in a visually structured layout.
- [ ] Each item clearly shows the submitter’s name and message.
- [ ] The page remains readable for short and long wishes on mobile devices.
