# [FR-009] Shareable Contribution Links

## Labels
`Future`, `enhancement`, `sharing`

## User Story
As the celebrant, I want to share a specific memory or collection view, so that I can spotlight special moments with others.

## Proposed Solution

### Overview
Add permalink support for individual contributions or filtered gallery views after the core v1 experience is stable.

### Implementation Flow
1. Define canonical public URLs for contribution detail or filtered collection states.
2. Add share UI where it feels natural.
3. Ensure deleted content cannot remain accessible from stale links.

### Technical Approach

```ts
type ShareTarget = {
  kind: 'contribution' | 'gallery-view'
  slug: string
}
```

### Key Considerations
- URL structure should remain stable.
- Shared media pages should preserve the site’s celebratory look.
- Future privacy needs may influence how direct links are handled.

## Acceptance Criteria

- [ ] A contribution or collection can have a stable public link.
- [ ] Shared links resolve to an intentional branded viewing experience.
- [ ] Deleted content is not publicly accessible through old share links.
