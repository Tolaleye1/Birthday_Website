# [FR-006] Admin Dashboard with Approval Flow

## Labels
`MUS`, `enhancement`, `admin`

## User Story
As the host admin, I want to review and remove submissions from one place, so that I can keep the site tidy without a full user system.

## Proposed Solution

### Overview
Provide an admin dashboard at `/admin` with a two-step approval-gated access flow and full CRUD for submissions and Laitan's Gallery items.

### Implementation Flow
1. Visitor enters email → "Request Access" → `POST /api/admin-request`
2. Notification email sent to site owner (`olaleyetomisin15@gmail.com`) via Resend with Approve/Reject links
3. **Approve:** magic link generated and sent to requester → they click and land on `/admin` logged in
4. **Reject:** requester gets a polite rejection email
5. Authenticated admin sees submission table with type filters and delete actions
6. Admin can upload/delete Laitan's Gallery items (photos + videos)

### Technical Approach

```ts
// Admin request table
type AdminRequest = {
  id: string
  requester_email: string
  status: 'pending' | 'approved' | 'rejected'
  approval_token: string
  created_at: string
}

// Gallery management
type LaitanGalleryItem = {
  id: string
  asset_path: string
  asset_url: string | null
  caption: string | null
  display_order: number
  media_type: 'photo' | 'video'
  created_at: string
}
```

### Key Considerations
- Admin access is gated through a human approval step — no open registration.
- Delete actions include a confirmation dialog.
- Delete is atomic — removes both DB record and storage file.
- Laitan's Gallery management accepts both image and video uploads.
- Public pages stop showing deleted items immediately.

### Dependencies
- `resend` npm package for transactional emails
- `RESEND_API_KEY` environment variable

## Acceptance Criteria

- [x] Only approved users can access the dashboard (approval flow via email). ✅
- [x] The dashboard lists text, photo, and video submissions with type filters. ✅
- [x] Admin can delete a submission and its public presence is removed from the site. ✅
- [x] Admin can upload and delete Laitan's Gallery items (photos and videos). ✅
