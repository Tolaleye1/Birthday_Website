# [FR-006] Admin Login and Dashboard

## Labels
`MUS`, `enhancement`, `admin`

## User Story
As the host admin, I want to review and remove submissions from one place, so that I can keep the site tidy without a full user system.

## Proposed Solution

### Overview
Provide a simple admin login flow and dashboard where the host can view all contribution types and delete unwanted items.

### Implementation Flow
1. Authenticate the admin through an allowlisted magic-link flow.
2. Show all contributions with filters or tabs by type.
3. Allow deletion of both the database record and linked file where applicable.

### Technical Approach

```ts
type AdminSubmissionRow = {
  id: string
  type: 'text' | 'photo' | 'video'
  submitterName: string
  createdAt: string
  isDeleted: boolean
}
```

### Key Considerations
- Admin flows should stay simple and low-maintenance.
- Delete actions should include a confirmation step.
- Public pages should stop showing deleted items immediately.

## Acceptance Criteria

- [ ] Only the configured admin can access the dashboard.
- [ ] The dashboard lists text, photo, and video submissions.
- [ ] Admin can delete a submission and its public presence is removed from the site.
