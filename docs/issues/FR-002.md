# [FR-002] Dedicated Video Upload Flow

## Labels
`MUS`, `enhancement`, `submissions`

## User Story
As a guest, I want to submit a short video greeting, so that I can share a more personal birthday message.

## Proposed Solution

### Overview
Build a dedicated video-upload page that accepts a short clip, submitter name, and optional caption while enforcing the 90-second limit and media validation rules.

### Implementation Flow
1. Collect name, optional caption, and video file.
2. Validate file type, size, and duration before final submission.
3. Upload directly to storage and then save metadata to the contributions table.

### Technical Approach

```ts
type VideoSubmissionInput = {
  submitterName: string
  caption?: string
  fileName: string
  mimeType: string
  fileSize: number
  durationSeconds: number
}
```

### Key Considerations
- Upload progress should be visible.
- Validation must happen on both client and server paths.
- Mobile users need clear guidance about duration and file expectations.

## Acceptance Criteria

- [ ] Guests can submit a video with a required name and optional caption.
- [ ] Videos longer than 90 seconds are rejected with a clear message.
- [ ] Successful uploads create a stored media asset and a linked contribution record.
